# AI Resume Analyzer

An AI-powered ATS Resume Analyzer built using:

- NLP
- Sentence Transformers
- Groq LLM
- Streamlit

## Features

- ATS Match Score
- Resume Skill Extraction
- Missing Skills Detection
- AI Resume Feedback
- Resume Tailoring
- Internship Recommendations
- AI Career Copilot
